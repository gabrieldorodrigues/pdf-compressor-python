# 🗜️ Compressor Universal

Um aplicativo desktop simples e poderoso para comprimir seus arquivos PDF e imagens de forma rápida e eficiente!

## 🎯 O que ele faz?

Imagina ter que enviar um PDF gigante por email ou uma foto que está muito pesada? Este app resolve isso! Ele diminui o tamanho dos seus arquivos mantendo a qualidade que você precisa.

## ✨ Por que você vai amar

- 🚀 **Super fácil de usar** - Apenas arraste, escolha o nível e pronto!
- 📱 **Interface limpa** - Sem confusão, direto ao ponto
- 🎯 **Funciona offline** - Não precisa de internet
- 💻 **App nativo** - Instala no seu computador como qualquer programa
- 🔒 **Seus arquivos ficam no seu PC** - Nada é enviado para internet

## 📋 O que você pode comprimir

### 📄 Documentos PDF

- Qualquer arquivo `.pdf`
- Ideal para enviar por email ou WhatsApp
- Reduz drasticamente o tamanho mantendo a legibilidade

### 🖼️ Fotos e Imagens

- Arquivos `.jpg`, `.jpeg`, `.png`
- Perfeito para redes sociais ou backup
- Ajusta qualidade e tamanho automaticamente

## 🎮 Como usar

1. **Baixe e instale** o aplicativo
2. **Escolha o tipo** - PDF ou Imagem
3. **Selecione seu arquivo** - Clique para navegar
4. **Escolha o nível** - Quanto quer comprimir
5. **Aperte comprimir** - E pronto! 🎉

### 🎚️ Níveis de compressão explicados

**Para documentos:**

- 🟢 **Leve** - Pouca compressão, máxima qualidade
- 🟡 **Médio** - Equilibrio perfeito (recomendado)
- 🔴 **Máximo** - Menor tamanho possível

**Para fotos:**

- 🟢 **Leve** - Ideal para impressão
- 🟡 **Médio** - Perfeito para compartilhar
- 🔴 **Máximo** - Para economizar espaço

## 🛠️ Para desenvolvedores

Se você quer rodar o código ou contribuir:

### Requisitos

- Node.js 16+
- npm

### Instalação

```bash
git clone https://github.com/gabrieldorodrigues/pdf-compressor-python.git
cd pdf-compressor-python
npm install
```

### Comandos úteis

```bash
npm run electron-dev    # Rodar em modo desenvolvimento
npm run build          # Gerar build de produção
npm run dist           # Criar executável
```
