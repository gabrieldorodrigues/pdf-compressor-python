# Compressor Universal

Aplicativo desktop para comprimir arquivos PDF e imagens de forma rápida e eficiente.

## O que faz

Reduz o tamanho de arquivos PDF e imagens (.jpg, .jpeg, .png) mantendo a qualidade.

## Principais recursos

- Fácil de usar
- Interface simples
- Funciona offline
- App nativo para desktop
- Privacidade: nada é enviado para a internet

## Tipos de arquivo suportados

- PDF (.pdf)
- Imagens (.jpg, .jpeg, .png)

## Como usar

1. Baixe e instale o aplicativo
2. Escolha o tipo de arquivo
3. Selecione o arquivo
4. Escolha o nível de compressão
5. Clique em "Comprimir"

## Níveis de compressão

**Documentos:**

- Leve: pouca compressão, máxima qualidade
- Médio: equilíbrio entre tamanho e qualidade
- Máximo: menor tamanho possível

**Fotos:**

- Leve: ideal para impressão
- Médio: perfeito para compartilhar
- Máximo: para economizar espaço

## Para desenvolvedores

Requisitos:

- Node.js 16+
- npm

Instalação:

```bash
git clone https://github.com/gabrieldorodrigues/pdf-compressor-python.git
cd pdf-compressor-python
npm install
```

Comandos úteis:

```bash
npm run electron-dev    # Rodar em modo desenvolvimento
npm run build           # Gerar build de produção
npm run dist            # Criar executável
```
